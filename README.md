# 🔍 Equity Data QA Dashboard

A comprehensive Streamlit dashboard for validating financial data quality in equity research.

## Features

- **📊 Data Completeness Overview**: Visual matrix showing data coverage across companies
- **🏢 Company Analysis**: Detailed drill-down into individual company financials  
- **📈 Quality Validation**: Automated checks for data integrity issues
- **🔒 Secure Access**: Password-protected with user authentication
- **📥 Export Capability**: Download quality reports as CSV

## Financial Statements Supported

- Balance Sheet
- P&L Statement  
- Cash Flow Statement
- Quarterly Results

## Data Quality Checks

- Missing value detection
- Negative sales identification
- Extreme profit margin validation
- Zero asset flagging
- Cash flow anomaly detection

## Authentication

The dashboard includes built-in authentication with the following user roles:
- Equity Analysts
- Team Leads  
- Administrators

## Technology Stack

- **Frontend**: Streamlit
- **Database**: MongoDB
- **Visualization**: Plotly
- **Data Processing**: Pandas

## Deployment

Deployed on Streamlit Cloud with:
- Secure credential management
- Private repository access
- Invite-only sharing

## Usage

1. Log in with provided credentials
2. Navigate between Overview, Company Details, and Quality Analysis views
3. Export findings for further analysis
4. Monitor data quality across all equity holdings

---

**Note**: This dashboard contains proprietary financial data and is restricted to authorized users only.
